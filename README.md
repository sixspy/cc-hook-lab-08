## 主链

**端点登记 → 事件入队（落库即脱敏） → 签名投递 → 失败重试与死信 → 投递账互证**

页面：投递台 · 端点名册 · 事件队列 · 投递流水 · 死信匣 · 签名规 · 投递互证 · 事件详情

## 载荷脱敏（hook-08）

- 工程形态：**独立快照表**。快照冻结脱敏规则指纹（`mask-v1`）、只读，**不存任何载荷原文**，拒明文回刷；不采用「双写两轨」并存形态。
- 入队与脱敏**同成同败**：同一事务内建快照、遮罩密钥字段、写现行摘要，任一步失败整笔回滚。
- 现行摘要 / 事件列表 / 事件详情 / 导出**同票同源**，只读脱敏集；读侧二次遮罩兜底，列表永不出现明文。
- 事件详情与投递互证给出**摘要脱敏态、字段遮罩、对账结论、中文提示**；明文残留判「待补档 / 对账失败」，不冒充已脱敏。
- 对账影子只在互证时联查计算，不落事件表 / 互证批次等正式集合。

> 题材声明：Webhook 投递控制台。**不是**工单客服 / OA / CRM / 预约 / 电商订单（官方雷同禁区）。**不是**数据工程采集入库。
